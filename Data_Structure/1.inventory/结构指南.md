## UI 文件夹大致结构

```
UI/
├── index.html              # 入口，按顺序加载所有 script/css
├── css/                    # 样式（背包在 panels/backpack-panel.css）
├── data/
│   ├── ui-schemas/         # 面板「配置」：分类名、标签文字等（不含存档数据）
│   └── templates/          # 新建存档用的默认 JSON 模板
├── js/
│   ├── game-data.js        # 读存档、合并数据、提供给各面板
│   ├── inventory-utils.js  # 新：把 Data/Saves/.../inventory/ 转成 UI 能用的格式
│   ├── equipment-utils.js  # 装备字段格式化（伤害、修正值、类型标签）
│   ├── app.js              # 侧边栏、打开存档
│   ├── top-bar.js          # 顶栏标签，点「背包」时挂载面板
│   ├── chat.js             # 对话区
│   ├── llm/                # 与 LLM 通信、同步 [INVENTORY_SYNC] 等
│   └── panels/
│       ├── panel-common.js
│       └── backpack-panel.js   # 背包三栏 UI 的渲染
└── templates/              # 游戏/聊天页面骨架
```

## 背包相关数据流

```
Data/Saves/xxx/inventory/
  all_*.json + list_*.json
        ↓
inventory-utils.js     加载 + 合并（只取 identity=pc）+ 分类映射
        ↓
game-data.js           getPanelData('backpack') → resolveInventoryForUi()
        ↓
{ wealth, categories: { consumable, tool, equipment, key } }
        ↓
backpack-panel.js      三栏：分类 | 物品名 | 详情
        ↑
panels.json            分类 id 与中文标签（消耗品/道具/…）
```

**`inventory-utils.js` 的职责**：和磁盘 JSON 格式打交道——读哪些目录、找 PC 背包、把 `list_*` 数量与 `all_*` 详情拼成统一对象。面板代码不直接读 `all_equipment.json`。

**`backpack-panel.js` 的职责**：只消费已经整理好的 `{ wealth, categories }`，负责 DOM 展示。

**`equipment-utils.js`**：被 `inventory-utils`（提取装备伤害/修正）和 `backpack-panel`（显示「武器」「+1」）共用。

## 想改「呈现哪些字段、空/0 跳过」应改哪几个文件？

| 想改什么 | 改哪个文件 |
|----------|------------|
| 新 JSON 字段 → UI 对象（如 rarity、weight、effects） | **`inventory-utils.js`** 的 `buildUiInventoryItem` / `extractEquipmentDisplay` |
| 哪些 `list_*` 进背包、quantity≤0 是否过滤 | **`inventory-utils.js`** 的 `getPcInventoryEntries`、`UI_BACKPACK_CATEGORY_SOURCES` |
| 财产怎么算、显示格式 | **`inventory-utils.js`** 的 `formatWealthFromCurrency` |
| 详情页显示哪些行、空/0 是否跳过 | **`backpack-panel.js`** 的 `renderDetail`（主要改这里） |
| 左侧分类名称、顺序 | **`data/ui-schemas/panels.json`** 的 `backpack.categories` |
| 列表只显示名字还是「名字 x3」 | **`backpack-panel.js`** 的 `renderList` |
| 样式微调（字号、间距） | **`css/panels/backpack-panel.css`** |

**一般分工**：
- **数据从哪来、映射成什么字段** → `inventory-utils.js`
- **哪些字段画出来、空值跳过** → `backpack-panel.js`

例如「修正值为 0 不显示」：在 `backpack-panel.js` 里把

```javascript
if (item.modifier !== undefined && item.modifier !== null && item.modifier !== '') {
```

改成同时判断 `normalizeModifier(item.modifier) !== 0` 即可，不必动 `inventory-utils.js`。

例如「详情要显示重量 `weight`」：先在 `buildUiInventoryItem` 里加上 `weight: allItem?.weight`，再在 `renderDetail` 里加一行判断非空再输出。

## 通常不用动的文件

- **`game-data.js`**：除非改加载路径或 `[INVENTORY_SYNC]` 写入方式
- **`top-bar.js`**：只负责打开面板，不管字段
- **`equipment-utils.js`**：仅当装备数字/标签的**格式化规则**要变时

如果你之后要做「按物品类型不同详情模板」（消耗品显示 effects、任务物品显示 task_hint），建议在 `inventory-utils.js` 多带几个字段，在 `backpack-panel.js` 的 `renderDetail` 里按 `item.category` 或 `item.tag` 分支渲染。
