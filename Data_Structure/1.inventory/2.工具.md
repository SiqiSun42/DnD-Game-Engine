工具的字段和消耗品大体一致，只是效果类型可能略有不同+有耐久度/使用次数字段。
区分工具和消耗品的方法只是“使用完后是否对物品本身有损耗”。

---

## 统一的效果类型（通用，覆盖消耗品和工具）

| 类型 | 说明 | 适用物品举例 | 分类标签可能为 |
|------|------|-------------|-------------|
| `恢复` | 恢复生命值或法术位 | 治疗药水 | 消耗品 |
| `伤害` | 对目标造成伤害 | 炽火胶、毒药 | 消耗品 |
| `增益` | 暂时提升属性或检定 | 巨人力量药水、鹰眼药水 | 消耗品 |
| `减益` | 暂时削弱 | 致盲粉 | 消耗品 |
| `施法` | 施展一个法术 | 卷轴 | 消耗品 |
| `解除` | 解毒、治疗疾病 | 解毒剂 | 消耗品 |
| `照明` | 提供光源 | 火把、提灯 | 消耗品 / 工具 |
| `检定` | 提供技能检定优势或加值 | 盗贼工具、放大镜 | 工具 |
| `动作` | 执行特定动作或交互 | 绳索、医疗包 | 工具 |
| `防护` | 提供临时防护或环境隔离 | 帐篷、防毒面具 | 工具 |
**关键点**：`照明`、`检定`、`动作`、`防护` 不只属于工具。只要符合“用完本体消失”就是消耗品；本体不消失就是工具，次数用尽后仍可补充。

---

### 示例：火把（消耗品，使用后消失，但有`照明`效果）

```json
{
  "标签": "消耗品",
  "名称": "火把",
  "数量": 3,
  "简介": "一根浸满树脂的粗木棍，点燃后可燃烧约1小时。",
  "效果": [
    {
      "类型": "照明",
      "作用对象": "区域",
      "范围": 20,   // 默认单位为尺
      "时间": { "持续时间": 60 },
      "描述": "火把噼啪作响，照亮四周。"
    }
  ],
  "使用条件": {
    "动作类型": "动作",
    "目标": "自己"
  },
  "重量": 1
}
```

**为什么它是消耗品？** 因为1小时后火把烧完，本体消失，不可补充。字段上不写 `最大使用次数` 相关文本。

### 示例：提灯（工具，本体不消失，但有`照明`效果，需要补充次数）

```json
  "数量": 1,
  "简介": "一具黄铜提灯，需要加油才能点亮。",

```

### 边界情况：一个消耗品同时有多种效果（如火球术卷轴同时有`施法`、`伤害`和`照明`）

例如火球术卷轴虽然会被消耗掉，但它拥有多种效果。这说明“效果”字段是完全通用的，不因标签而变。

---

### 总结一下

- **效果类型是通用的**，消耗品和工具共同使用。
- 火把（用完消失）→ `标签: 消耗品`，也可有 `照明` 效果。
- 提灯（本体保留）→ `标签: 工具`，也可有 `照明` 效果，并附加次数字段。
- 魔法消耗品（如卷轴）可同时有多个不同类型效果（施法、伤害、照明等）。

这样处理，结构对应用最灵活，同时避免了人为割裂效果与分类的对应关系。
