通用宗教/意识形态放文化面板，区域特定习俗放地点简介，种族特定信仰放物种简介。这样避免了数据冗余，也方便城主按需查阅。

那么，文化面板只需要两种条目：**宗教**和**意识形态**。

---

**文化面板 JSON 模板**

```json
[
  {
    "名称": "海洋女神崇拜",
    "类型": "宗教",
    "简介": "信奉海洋女神，相信她掌管着一切水域、潮汐与海中生物。信徒认为每一次航行能否平安归来，全取决于女神的心情。",
    "核心教义": "敬畏海洋，不可贪婪索取。出海前必须向女神献上祭品，捕获过多或浪费海产将招致神罚。",
    "信奉者": "沿海城镇的渔民、水手，以及部分人鱼部族。",
    "主要传播区域": "剑湾沿岸、月影群岛及周边海域",
    "仪式与节日": "每年夏至的“潮汐祭”最为盛大，信徒会将满载鲜花与贡品的小船送入海中。",
    "禁忌": "不可在暴风雨中诅咒海洋，不可食用搁浅的鲸鱼。"
  },
  {
    "名称": "铁之意志",
    "类型": "意识形态",
    "简介": "一种在佣兵与战士间流传的信念，认为个体的意志力可以像钢铁一样被反复锻打而变得无坚不摧。追随者将此生视为一场永无止境的试炼。",
    "核心理念": "痛苦使人坚韧，失败是淬炼灵魂的炉火。只有经历过最残酷磨砺的人，才能成为自己的主宰。",
    "信奉者": "佣兵团、北方蛮族战士、部分矮人铁匠",
    "主要传播区域": "北方冰原、边境要塞"
  }
]
```

**字段说明**

| 字段 | 宗教 | 意识形态 |
|------|------|----------|
| `名称` | 信仰的称呼 | 理论的名称 |
| `类型` | 固定为“宗教” | 固定为“意识形态” |
| `简介` | 教派概述 | 理论概述 |
| `核心教义/核心理念` | 教派的根本信条 | 理论的根本观点 |
| `信奉者` | 典型信徒群体（人种、职业、地区人群） | 同左 |
| `主要传播区域` | 该信仰盛行的地理范围 | 该理论盛行的范围 |
| `仪式与节日` | 教派特有的庆典或仪式（可选） | （通常为空，可省略） |
| `禁忌` | 教派禁止的行为（可选） | （通常为空，可省略） |
