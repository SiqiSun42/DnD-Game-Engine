**组织结构总览**

**模块一：基础信息**
描述这个组织“是什么”。

| 字段 | 说明 |
|------|------|
| `名称` | 组织正式名称 |
| `类型` | 犯罪集团 / 公会 / 魔法结社 / 骑士教团 / 宗教教派 / 秘密社团 / 政治派系 等 |
| `简介` | 一两句话概述，DM 介绍组织时使用 |
| `规模` | 大概人数范围，如“约 200 人”“遍布大陆，数千人” |
| `目标` | 组织的核心目的，如“控制全国的地下贸易”“守护王国免受亡灵侵袭” |
| `标志` | 组织的符号、徽章、暗记 |
| `信条` | 口号、座右铭、接头暗语 |
| `活动范围` | 组织主要出没的区域 |
| `资金来源` | 如何获取资金（捐赠、税收、商业、掠夺等） |
| `成员招募方式` | 如何吸纳新人（公开招募、秘密邀请、世袭、考验入会等） |
| `创始人及著名成员` | 历史上的创立者或当代知名人物 |
| `知名事件` | 该组织在历史上参与过的重要事件 |

**模块二：关系**
描述组织在世界中的位置。

| 字段 | 说明 |
|------|------|
| `风评` | 普通人对该组织的普遍看法（正面 / 中立 / 负面）及一句话描述 |
| `盟友` | 数组，每个元素包含盟友组织名称及关系简述 |
| `敌人` | 数组，每个元素包含敌对组织名称及关系简述 |

**模块三：服务与任务**
描述组织能为玩家提供什么。

| 字段 | 说明 |
|------|------|
| `服务` | 数组，每个元素包含服务名称、描述、价格/条件。与地点服务字段格式一致 |
| `任务` | 数组，每个元素包含任务名称、描述、奖励简述。可链接至详细任务条目 |

**模块四：与玩家团队的关系**
动态追踪组织对玩家团队的态度。

| 字段 | 说明 |
|------|------|
| `好感度` | 整数，范围 -99 到 99，默认为 0 |
| `关系描述` | 一句话描述当前关系状态，如“中立”“因某次任务被列为追查对象” |
| `关系影响` | 当前关系状态下产生的实际影响，如“好感度低于 -30 时，该组织所有服务不可用；低于 -60 时，组织会派出刺客追杀团队” |
